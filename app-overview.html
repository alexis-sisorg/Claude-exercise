Client-Side Routing

Built-in Angular Router is wired and ready. Routes are declared in app.routes.ts and rendered through <router-outlet> — add new views without full page reloads.

⚡

Hot Module Replacement

Component HMR is enabled out of the box via the Vite-based dev server. Edit a component and see the change instantly in the browser — no full refresh, no lost state.

🖥️

Welcome Shell UI

The default landing page renders the app title dynamically via Angular template binding ({{ title }}), quick-access links to the Angular docs ecosystem, and social links — all generated from a typed data array using the modern @for control-flow syntax.

🎨

Scoped & Global Styling

Global styles live in src/styles.css. Each component gets its own encapsulated CSS file — zero leakage between components by default.

📦

Standalone Component API

No NgModules required. Every component is self-declaring using Angular 19's standalone API — dependency injection, imports, and providers are co-located at the component level.

🔧

Optimized Production Build

A single ng build produces a production bundle with output hashing, tree-shaking, and enforced budget limits (500 kB warning / 1 MB hard cap for the initial chunk).

Expansion path

What the scaffold is ready for

Feature Routes

Add path definitions to app.routes.ts — lazy-loaded feature modules are supported out of the box.

HTTP Services

Provide provideHttpClient() in app.config.ts to connect to any REST or GraphQL API.

State Management

Drop in NgRx Signals, Akita, or plain Angular Signals for reactive global state — no structural changes required.

Auth Guards

Angular's functional route guards (canActivate) slot directly into route definitions for protecting views.

Build Pipeline

  • Vite-based builder via @angular-devkit/build-angular
  • ESBuild for blazing-fast TypeScript transpilation
  • Output hashing in production for cache busting
  • Initial bundle target: 137 kB (polyfills + main + styles)
  • Hard budget cap: 1 MB — build fails above this
🔌

Dependency Injection

  • Root-level providers declared in app.config.ts
  • provideRouter(routes) — Angular Router injected
  • provideZoneChangeDetection with event coalescing for fewer CD cycles
  • No NgModule boilerplate — fully standalone architecture
⚙️

TypeScript Configuration

  • Target & Module: ES2022
  • Strict mode fully enabled
  • noImplicitOverride, noImplicitReturns enforced
  • Angular strict templates — full type-checking inside HTML
  • Module resolution: bundler (Vite-native)
🌊

Reactivity Model

  • RxJS 7.8 for async streams and observables
  • Zone.js 0.15 drives automatic change detection
  • Event coalescing reduces unnecessary re-renders
  • Angular Signals available for fine-grained reactivity

Database

No database is currently integrated. This is a pure frontend SPA. All data at this stage lives in component state or would be fetched from an external API once HttpClient is provided.
